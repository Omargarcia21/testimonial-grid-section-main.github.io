# Solución al Desafío de Frontend Mentor: Sección de Testimonios en Cuadrícula

![Badge](https://img.shields.io/badge/Estado-Completado-brightgreen)  
Este es mi solución al desafío **Testimonials Grid Section** de Frontend Mentor. El objetivo era crear una página estática con un diseño responsivo utilizando **CSS Flexbox** y **CSS Grid**, mostrando una sección de testimonios organizada en una cuadrícula.

**Desafío de Frontend Mentor:** [Testimonials Grid Section](https://www.frontendmentor.io/challenges/testimonials-grid-section-Nnw6J7Un7)  
**Live Demo:** [Ver Proyecto en Vivo](https://omargarcia21.github.io/testimonial-grid-section-main.github.io/)

## Descripción del Proyecto

Este proyecto es una página estática que presenta una sección de testimonios organizada en una cuadrícula. La página incluye:

- Un diseño de cuadrícula (Grid) que muestra varios testimonios con diferentes estilos y colores.
- Información de cada testimonio, incluyendo la foto del usuario, su nombre, su rol y su comentario.
- Un diseño responsivo que se adapta a diferentes tamaños de pantalla, desde dispositivos móviles hasta desktop.

El diseño es completamente responsivo, utilizando **CSS Flexbox** y **CSS Grid** para organizar los elementos de manera eficiente y visualmente atractiva.

## Tecnologías Utilizadas

- **Lenguajes de Programación**: HTML, CSS, JavaScript.
- **Metodologías CSS**: Flexbox y Grid para la disposición de los elementos.
- **Diseño Responsivo**: Compatible con dispositivos móviles, tablets y desktop.

## Instrucciones de Instalación y Uso

Este proyecto es una página web estática, por lo que no requiere instalación.
